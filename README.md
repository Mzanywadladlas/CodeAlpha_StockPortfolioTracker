README: Stock Portfolio Tracker
Repository name: CodeAlpha_StockPortfolioTracker
Title: CodeAlpha Stock Portfolio Tracker (Python)

Project Description:
This project is a simple Stock Portfolio Tracker that calculates the total investment value based on user input and predefined stock prices.

Features:
1. User inputs stock name and quantity
2. Uses a hardcoded dictionary for stock prices
3. Calculates total investment value
4. Option to save results to a file (optional)
5. Console-based application
   
Technologies Used:
* Python
* Dictionaries
* Input and output
* Basic arithmetic
* File handling (was added as optional)
  
How to Run the Project:
1. Open Command Prompt or Terminal
2. Navigate to the project folder
3. Run the command:
python stock_tracker.py

Example Workflow:
** Enter stock name (e.g., AAPL, TSLA)
** Enter quantity
** Program calculates total portfolio value

Concepts Demonstrated:
*** Dictionaries
*** User input handling
*** Calculations
*** File saving (.txt or .csv)
*** Basic data processing
